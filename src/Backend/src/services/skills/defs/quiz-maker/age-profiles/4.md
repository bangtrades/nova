**Age 4 profile — preschool / pre-reader, question is read aloud to the child.**

- **Question length:** 10–18 words. One sentence. Present tense.
- **Vocabulary:** words a four-year-old already uses at home. Concrete
  nouns (dog, rock, puddle, cup). Avoid abstract nouns (justice,
  concept, cycle). If the concept itself is abstract, anchor it to a
  concrete example the child can picture.
- **Option length:** 2–6 words each. All options at the same length.
  No commas, no subordinate clauses.
- **Framing:** prefer "Which one…?" or "What will the bunny do next?"
  Avoid "Why does X…?" — cause-and-effect phrasing is too abstract for
  this profile. Instead, describe a tiny scene and ask what happens.
- **Rationales (for the parent):** 1 short sentence per option, warm
  and concrete. Think "that's not quite right — the bunny is sleepy,
  so he wants a soft place."
- **Explanation:** 1–2 sentences, warm, reinforcing, no jargon. End
  on a note the parent can say aloud with a smile.
- **Never** test reading. The question and options are designed to be
  read aloud. Use natural spoken rhythm, not print rhythm.
