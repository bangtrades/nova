## Critical lessons from the prior session — DO and DON'T

### DO

- **Trust but verify agent claims.** Last batch's recaps said "BUILD SUCCEEDED" / "35 tests pass" — neither verified. Always check `git diff` to see what they actually changed, and have bang run the actual build/tests Mac-side.
- **For new iOS source files**, use Xcode `File → Add Files` (NOT raw pbxproj edits). The Xcode UI writes the correct entries; hand-edits broke the project twice this session, especially when the filename contained `+`.
- **For SPM packages**, just create the file in the package's `Sources/` or `Tests/` — SPM auto-globs. No pbxproj at all.
- **For SPM package *dependencies* of an app target**, use Xcode's General → Frameworks/Libraries → `+`. Never hand-edit the `XCSwiftPackageProductDependency` entries.
- **Stage commits explicitly** (`git add <files>`), never `git add -A`. The repo currently has loose art PNGs in `src/` root that would be swept in.
- **Reconcile agent slice work against the SPRINT-V2 tracker** after each batch. Flip story statuses. The tracker is the project's instrument panel.
- **Write slice reports** for every agent run, into `docs/sprint-runs/`. Format: see `V2-S4-fixpack-2026-05-22.md`. Bake the instruction into every agent slice brief so the slice self-documents.

### DON'T

- **Don't blind-edit the pbxproj** for anything beyond a simple file add/remove of a non-`+` filename matching an existing UUID pattern. Package dependencies, target memberships, build phases for non-trivial cases — Xcode UI.
- **Don't commit a knowingly-broken intermediate state.** If a refactor needs a manual Xcode step in the middle, leave the working tree uncommitted and tell bang the exact step.
- **Don't `git add -A`** — see above.
- **Don't commit the Cortana vault to a git repo.** It's NOT git-tracked, by design (Obsidian/filesystem sync). Vault edits are saved on write — no commit, no flag, just edit.
- **Don't trust the existing `docs/architecture.mermaid` without re-checking** — it was wildly out of date until this session (fixed now). Diagram rot is a hazard.
- **Don't use Swift's `.iso8601` `DateDecodingStrategy`** for backend payloads — Prisma emits fractional seconds and `.iso8601` rejects them. Use `APIClient.makeJSONDecoder()` factory. There's a ContractTests guard test that documents this — don't "simplify" it back.
- **Don't put a `+` in any new iOS Swift filename** added via pbxproj. It broke Xcode container loading once this session.
- **Don't tell agents to "review the Cortana vault" before executing a slice** — 69 historical slice logs are wasted context for execution work. The slice briefs are deliberately self-contained. The vault review's value is upstream (planning).
